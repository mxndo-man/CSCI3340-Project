Every component on one page. Copy the markup from templates/components/; the colors and type sizes live in styles/styles.css. Only shown when DEBUG is on.

Colors

Use only these. Each one is a class like bg-action or text-ink-soft.

  • canvas (page)
  • bar (header)
  • paper (boxes)
  • sunk (hover, selected)
  • line (dividers)
  • edge (pixel edges)
  • line-strong (inputs)
  • ink (text)
  • ink-soft
  • ink-muted (quiet text)
  • action (buttons)
  • action-hover
  • action-ink (links)
  • action-soft (selected)
  • gold (look here)
  • gold-ink
  • gold-soft
  • good-ink
  • good-soft
  • alert-ink
  • alert-soft
  • info-ink
  • info-soft
  • band-pine (footer)
